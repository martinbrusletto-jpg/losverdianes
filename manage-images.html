Exterior image manager

Exterior photography is separated from the rest of the presentation. You can add, remove or reorder exterior images without touching the page layout.

Fastest method

Open the image list below. Under exterior:[ ], paste one line per photo. Use either a public image URL or a file path after uploading the image to the repository.

exterior:[
  {src:"https://.../pool.jpg",label:"Pool terrace"},
  {src:"https://.../facade.jpg",label:"Garden facade"}
]

Delete a line to remove a photo. Move a line up or down to change its position. If the list is empty, the exterior section disappears automatically.
